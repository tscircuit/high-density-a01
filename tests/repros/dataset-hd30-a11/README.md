# dataset-hd30 A11 regressions

These native-bound `NodeWithPortPoints` fixtures come from
[`tscircuit/dataset-hd30`](https://github.com/tscircuit/dataset-hd30) at
commit `996571b00d51fa635a1410d38268fc4b18bf4d82`.

They cover the eight dataset-hd30 nodes solved by
`HighDensitySolverA11` with Pipeline 9 copper dimensions, a
100,000-iteration cap, and no node growth. The directory includes the original
six native-size solves plus the history-aware displacement and shortest-first
ordering regressions.
