# dataset-hd30 A12 regressions

These fixtures are the eight `tscircuit/dataset-hd30` nodes solved by A12 at
its default 0.05 mm fine pitch, 16-cell perimeter band, and 0.20 mm coarse
middle pitch. Five fixtures unique to this directory were copied from dataset
commit `996571b00d51fa635a1410d38268fc4b18bf4d82`; the three shared A11/A12
fixtures are imported from the adjacent A11 regression directory.
